# 推导记录：把 Part II 做深，而不改变题目

## 目标和贡献边界

用户选择的方向是简化、统一原问题的解法，而不是引入随机化投票等新模型。
现有报告已经解决了 K=3 的八格概率表。这里研究所有奇数 K 的**相同边际、相同两两相关性**，给出精确界、达到界的构造，以及“投票必定优于一个成员”的精确条件。

对称化、离散矩问题、三点极值分布都属于经典方法，不能单独作为原创性声明。
项目希望形成的具体贡献是：一套可手算的线性数量证书、统一的初等证明，以及由此导出的显式决策阈值。是否已有完全相同的表述，必须结合阅读记录判断；独立推导不等于文献首创。

## 1. 用计数代替整个二进制向量

设 K=2m+1，t=m+1，S 为投对人数，μ=Kp，ν=K(K−1)r，
r=p²+ρp(1−p)。对任意可行联合分布随机排列编号，目标和约束不变。
反过来，任意 S 的分布，条件于 S=s 均匀选 s 个成员投对，即可实现所要求的每个边际和每个两阶矩。

因此恰好只需指定 E S=μ 和 E[S(S−1)]=ν。注意：这不假定原来的分类器可交换；这是极值问题的无损对称化。

可行矩的区域是点 v_s=(s,s(s−1)), s=0,…,K 的凸包。
令 a=floor(μ)，其条件为

    0 ≤ μ ≤ K,
    2aμ−a(a+1) ≤ ν ≤ (K−1)μ.

下边由相邻整数混合达到，上边由 0、K 混合达到。固定 μ 再混合这两种分布即可填满区间。

## 2. 仅 O(K) 个二次证书

以下函数在每个整数 s=0,…,K 上都不超过 1{s≥m+1}：

    0,
    h(s)=s(s−m)/[K(K−m)],
    g_j(s)=1−(s−j)(s−j−1)/[(j−m)(j+1−m)],
        j=m+1,…,K−1.

对 g_j，s≤m 时乘积至少是分母；s≥m+1 时两个相邻整数的乘积非负。
这一步揭示了连续矩界丢掉的信息：相邻整数之间没有可能的 S。

取期望得到精确下界：

    B_K(μ,ν) = max(0,
      [ν−(m−1)μ]/[K(K−m)],
      max_j {1−[ν−2jμ+j(j+1)]/[(j−m)(j+1−m)]}).

## 3. 为什么一定达到，而不只是一个不等式

从凸多边形的顶点 v_m 作扇形分割：

- 低计数区域 conv(v_0,…,v_m)：支持全部 ≤m，准确率为 0；
- 三角形 conv(v_0,v_m,v_K)：在三个顶点上 h 等于目标；
- 三角形 conv(v_m,v_j,v_{j+1})：在三个顶点上 g_j 等于目标。

这些区域覆盖整个可行矩多边形。所在三角形的重心坐标就是达到下界的概率。
低计数区域也可用相邻扇形三角形实现。二维图形和三个线性方程足够，不需要调用一般 LP 对偶或高阶矩理论。

上界由 S→K−S 得到：

    A_max = 1−B_K(K−μ, K(K−1)−2(K−1)μ+ν).

## 4. 再把 O(K) 化为 O(1)

令 d=μ−m，v=E(S−m)²=ν−(2m−1)μ+m²，将 j=m+a。
相邻证书的期望为 G_a=[(2a+1)d−v]/[a(a+1)]，a=1,…,m。

    G_a−G_(a+1) = 2[(a+1)d−v]/[a(a+1)(a+2)].

若 d≤0，所有 G_a≤0。若 d>0，序列先增后减，取
a=clip(floor(v/d),1,m) 即可找到最大者，整数比值时允许并列。
因此只比较 0、h 的期望和一个 G_a，常数次运算即可求精确下界。
这给出本文“简化解法”的具体可检查内容；相邻证书相减的这一行证明应保留。

## 5. 精确的“保证收益”阈值

取 1/2<p<1。令

    x = [Kp−(1−p)m]/p,
    j = floor(x),
    ν_* = (1−p)m(m−1) + p[2jx−j(j+1)],
    ρ_* = [ν_*/(K(K−1))−p²]/[p(1−p)].

则在**可行的** ρ 上，A_min>p 当且仅当 ρ<ρ_*。

证书证明：h 的期望最多是 p，0 也不可能超过 p。
g_j 的期望超过 p 等价于

    ν < T_j = 2jKp + (1−p)(j−m)(j+1−m) − j(j+1).

T_j 是关于 j 的凹二次式，最大值在 j=floor(x)（x 为整数时可能有相邻并列），且最大值正是 ν_*。

直接达到：令 θ=x−j，在 S=m,j,j+1 分别放概率

    1−p, p(1−θ), pθ.

这时 E S=Kp，ν=ν_*，投票准确率恰好是 p。
将它与 P(S=K)=p, P(S=0)=1−p 的完全同步分布混合，可实现从 ν_* 到最大 ν 的每个矩，同时保持准确率 p。因此整个阈值以上区域都不能保证严格收益。

## 6. 取整修正与规模效应

设 d=Kp−m，θ=x−floor(x)，则

    ρ_* = d²/[K(K−1)p²] − 1/(K−1)
           + θ(1−θ)/[K(K−1)(1−p)].

最后一项是精确的整数修正，不能用连续 Cantelli 界冒充它。
对固定 p∈(1/2,1)，K→∞ 时

    ρ_* → (1−1/(2p))².

K=3 时化简为 ρ_*=1−2/(3p)。对 p=0.6，K=3 时为 −1/9；相关性为 0 并不足以保证三个投票者优于单个投票者。

与普通 C-bound 的保证收益阈值 ρ_C 相比，提升精确分解为：

    ρ_*−ρ_C = [(p−1/2)+1/(4K)]/[(K−1)p²]
                + θ(1−θ)/[K(K−1)(1−p)].

第一项来自失败阈值实际上为 S≤m（而非放宽至 S≤K/2）；第二项才来自整数支撑修正。
因此实验必须同时比较原 C-bound 和已经移动到 m 的 Cantelli 界，不能把纯粹阈值移动带来的收益全部称为新方法的贡献。
